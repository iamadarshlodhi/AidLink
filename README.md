# AidLink

AidLink is a community-based help platform that connects people who need assistance with people willing to help.

Users can create help requests, apply to requests, communicate through chat, manage applications, receive notifications, complete tasks, leave reviews, and use an SOS feature to alert their emergency contacts.

## Features

- 🔐 User authentication
  - Email/password authentication
  - Google authentication
  - OTP-based verification
  - Forgot password / reset password

- 👤 User profiles
  - Public profiles
  - Profile editing
  - Profile picture uploads
  - Skills and location
  - Ratings and reviews
  - Trust score and verification status

- 🤝 Help requests
  - Create and manage requests
  - Categories and task types
  - Online/offline modes
  - Request images
  - Deadlines and urgency
  - Apply to requests
  - Accept/reject applications

- 💬 Chat
  - Conversations between requesters and helpers
  - Message read status

- 🔔 Notifications
  - Application updates
  - Request status updates
  - Completion notifications
  - Review notifications
  - Notification preferences

- ⭐ Reviews
  - Rate completed tasks
  - Written feedback
  - Public review display

- 🚨 SOS
  - SOS alerts for requesters and accepted helpers
  - Emergency contact support
  - Email alerts through Resend

- 📊 Dashboard
  - Active requests
  - Applications
  - Completed tasks
  - Notifications
  - Ratings
  - Recent activity
